## المجال المفاهيمي الأول: التعامل مع بيئة الحاسوب
**المستوى:** السنة الأولى ثانوي (1AS)  
**الحجم الزمني الموصى به:** 02 ساعة

## الأهداف التعلمية
في نهاية هذه الوحدة، يكون المتعلم قادرًا على:
1. استيعاب **مفهوم نظام التشغيل (Operating System - OS)** ووظائفه الجوهرية في إدارة الحاسوب.
2. التعرف على الواجهة الحديثة لنظام **Windows 11** وتحديثاتها البيانية.
3. التمكن من مهارات **إدارة الملفات والمجلدات** عبر مستكشف الملفات (File Explorer).
4. التحكم في النوافذ المتعددة باستخدام تقنيات Snap Layouts وأسطح المكتب الافتراضية.

---

## 1. مفهوم نظام التشغيل ووظائفه (Operating System - OS)

### 1.1 التعريف
**نظام التشغيل (OS):** هو البرنامج الأساسي والوسيط الذي يدير جميع مكونات الحاسوب العتادية (Hardware) والبرمجية (Software)، ويوفر واجهة تفاعلية تُمكن المستخدم من إعطاء الأوامر وتشغيل التطبيقات بسهولة.

```
[ المستخدم ] <---> [ التطبيقات والبرامج ] <---> [ نظام التشغيل (OS) ] <---> [ المكونات المادية (Hardware) ]
```

### 2.1 وظائف نظام التشغيل الأساسية:
- **إدارة المعالج والعمليات (Process Management):** تنظيم تنفيذ البرامج والمهام وتوزيع وقت المعالج بينها.
- **إدارة الذاكرة الحية (Memory Management):** تخصيص مساحات الذاكرة للبرامج الحالية وتفرغتها عند الإغلاق.
- **إدارة الملفات والتخزين (File System Management):** تنظيم قراءة وكتابة وحفظ الملفات في الأقراص الصلبة.
- **إدارة أجهزة الإدخال والإخراج (Device Management):** التنسيق مع تعريفات التجهيزات (Drivers) لتشغيل الشاشة، الطابعة، الفأرة وغيرها.
- **توفير واجهة المستخدم (User Interface - UI):** تقديم واجهة رسومية سهلة الاستخدام (GUI - Graphical User Interface).

---

## 2. الواجهة البيانية الحديثة لنظام Windows 11

يتميز نظام **Windows 11** بتصميم حديث يركز على السلاسة وزيادة الإنتاجية:

### المكونات الرئيسية للواجهة:
1. **شريط المهام (Taskbar):** يقع في أسفل الشاشة وتتوسطه أيقونات التطبيقات المثبتة والنوافذ المفتوحة.
2. **قائمة ابدأ (Start Menu):** تتوسط شريط المهام، وتتيح الوصول السريع للتطبيقات المثبتة والملفات الأخيرة وزر الطاقة (إيقاف التشغيل/إعادة التشغيل).
3. **مركز الإشعارات والإعدادات السريعة (Quick Settings & Notification Center):** عند النقر على أيقونة الشبكة والصوت، يظهر لوح التحكم السريع بالسطوع، الصوت، Wi-Fi، وBluetooth.
4. **مستكشف الملفات (File Explorer):** النافذة الرئيسية لتصفح الأقراص والمجلدات، والتي أصبحت تدعم **علامات التبويب (Tabs)** لتفتح عدة مجلدات في نافذة واحدة.

## 3. ميزات زيادة الإنتاجية وإدارة النوافذ في Windows 11

### 1.3 محاذاة النوافذ الذكية (Snap Layouts & Snap Groups)
عند تمرير مؤشر الفأرة فوق زر التكبير (Maximize) بأي نافذة، تظهر خيارات تقسيم الشاشة تلقائيًا إلى:
- نصفين متساويين (50% / 50%).
- ثلاثة أقسام.
- أربعة أرباع شاشة.
تساعد هذه الميزة على العمل على عدة ملفات أو تطبيقات في نفس الوقت بمرونة عالية.

### 2.3 أسطح المكتب الافتراضية (Virtual Desktops)
تسمح بإنشاء أسطح مكتب متعددة وتسميتها (مثل: "سطح مكتب للدراسة"، "سطح مكتب للمشاريع الشخصية") للفصل بين مهام العمل وتنظيم المساحة.

## 4. إدماج وإدارة الملفات والمجلدات (File Management)

### 1.4 المفاهيم الأساسية:
- **الملف (File):** مجموعة من البيانات المخزنة تحت اسم امتداد محدد يحدد نوعه (مثل `.docx` للمستندات، `.xlsx` للجداول، `.pdf` للكتب الرقمية، `.jpg` للصور، `.py` لملفات البرمجة).
- **المجلد (Folder / Répertoire):** حاوية تنظيمية تُستخدم لتجميع الملفات والمجلدات الفرعية داخل الشجرة التنظيمية.

### 2.4 العمليات الأساسية على الملفات والمجلدات:

| العملية | الاختصار في الكيبورد | الوصف |
| :--- | :--- | :--- |
| **إنشاء مجلد جديد** | `Ctrl + Shift + N` | إنشاء حاوية جديدة في المسار الحالي |
| **نسخ (Copy)** | `Ctrl + C` | عمل نسخة طبق الأصل مع الاحتفاظ بالملف الأصلي |
| **قص (Cut / Move)** | `Ctrl + X` | نقل الملف من مساره الحالي إلى مسار جديد |
| **لصق (Paste)** | `Ctrl + V` | وضع الملف المنسوخ أو المقصوص في المكان المريح |
| **إعادة التسمية (Rename)** | `F2` | تغيير اسم الملف أو المجلد |
| **حذف إلى سلة المهملات** | `Delete` | نقل الملف إلى Recycle Bin لإمكانية استرجاعه |
| **حذف نهائي** | `Shift + Delete` | حذف الملف فورًا دون إرساله لسلة المهملات |
| **البحث (Search)** | `Ctrl + F` | البحث السريع عن ملف باسمه أو امتداده |

### 3.4 ضغط الملفات وفك الضغط (Compression):
- **الضغط (ZIP):** تحديد الملفات $\rightarrow$ النقر بالزر الأيمن $\rightarrow$ اختيار **Compress to ZIP file** لتصغير حجم البيانات وتسهيل إرسالها عبر البريد الإلكتروني.
- **فك الضغط:** النقر بالزر الأيمن على الملف المضغوط $\rightarrow$ اختيار **Extract All...**.

## نشاط تطبيقي (في المخبر)

### ورشة عمل: إدارة بيئة العمل ومستكشف الملفات
1. **الخطوة الأولى:** قم بإنشاء مجلد على سطح المكتب باسمك الكامل والصف (مثال: `أحمد_محمود_1AS1`).
2. **الخطوة الثانية:** أنشئ داخل مجلدك الرئيسي ثلاثة مجلدات فرعية:
   - `مستندات`
   - `جداول`
   - `صور`
3. **الخطوة الثالثة:** استخدم تقنية **Snap Layouts** لتقسيم الشاشة إلى نصفين:
   - النصف الأيمن: نافذة `مستكشف الملفات`.
   - النصف الأيسر: متصفح الإنترنت أو برنامج الكاتب.
4. **الخطوة الرابعة:** قم بضغط مجلدك الرئيسي بصيغة ZIP وتسميته `مشروع_الوحدة_03.zip`.
