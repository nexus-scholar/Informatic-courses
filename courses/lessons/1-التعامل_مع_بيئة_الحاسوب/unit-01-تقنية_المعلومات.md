# الوحدة 01: تقنية المعلومات والتطور التكنولوجي

## المجال المفاهيمي الأول: التعامل مع بيئة الحاسوب

**المستوى:** السنة الأولى ثانوي (1AS)  
**المدة الزمنية:** ساعتان

---

## الأهداف التعلمية

في نهاية الوحدة، يكون المتعلم قادرًا على أن:

1. يعرّف تكنولوجيا الإعلام والاتصال (TIC) ويشرح عناصرها.
2. يميز بين العتاد (Hardware) والبرمجيات (Software) والبيانات والموارد البشرية.
3. يذكر أمثلة لاستعمال التقنية في الدراسة والحياة اليومية بطريقة مسؤولة.
4. يصف بإيجاز تطور الحواسيب والأجهزة الذكية وأنظمة التشغيل.
5. يطبق قواعد صحية وأمنية أساسية عند استعمال الوسائط الرقمية.

---

## 1. تكنولوجيا الإعلام والاتصال (TIC)

تكنولوجيا الإعلام والاتصال، أو **TIC**، هي مجموعة الأجهزة والبرمجيات والشبكات التي تساعدنا على إنشاء المعلومات ومعالجتها وتخزينها وتبادلها.

يتكوّن المصطلح من ثلاث كلمات:

- **التكنولوجيا (Technologie):** توظيف المعرفة والمهارات والأدوات لحل مشكلة أو إنجاز عمل.
- **الإعلام (Information):** معلومات أو أفكار منظّمة يمكن فهمها والاستفادة منها.
- **الاتصال (Communication):** نقل المعلومات وتبادلها بين مرسل ومستقبل باستعمال وسيط مناسب.

### مثال من الحياة اليومية

عندما يرسل تلميذ ملفًا إلى أستاذه عبر البريد الإلكتروني: الحاسوب أو الهاتف هو الجهاز، والبريد الإلكتروني برنامج أو خدمة، وشبكة الإنترنت هي وسيلة الاتصال، والملف هو المعلومة المتبادلة.

## 2. كيف تتكامل مكوّنات TIC؟

لا تعمل التكنولوجيا بعنصر واحد؛ بل بتكامل عناصر متعددة:

| العنصر | معناه | أمثلة |
|---|---|---|
| العتاد (Hardware) | الأجزاء الملموسة | الحاسوب، الشاشة، لوحة المفاتيح، الهاتف، الموجّه (Router) |
| البرمجيات (Software) | البرامج التي تنفذ الأوامر | Windows 11، Ubuntu، LibreOffice، المتصفح |
| البيانات والمعلومات | ما يُخزّن أو يُعالج | نص، صورة، جدول علامات، ملف صوتي |
| الموارد البشرية | الأشخاص الذين يستخدمون أو يصممون النظام | تلميذ، أستاذ، مبرمج، تقني صيانة |
| الشبكات | وسائل ربط الأجهزة وتبادل البيانات | شبكة المؤسسة، الإنترنت، Wi-Fi |

### فوائد TIC

- تسريع الوصول إلى المعرفة والتواصل.
- تنظيم الملفات وحفظها واسترجاعها.
- دعم التعلم بالمحاكاة والعروض والأنشطة التفاعلية.
- تسهيل العمل الجماعي عند استعمالها باحترام القواعد.

### استعمال مسؤول

التكنولوجيا أداة نافعة عندما نتحقق من المعلومة، ونحترم خصوصية الآخرين، وننظم وقت الشاشة، ولا نشارك كلمات المرور أو الملفات الشخصية دون إذن.

## 3. تكنولوجيا الإعلام والاتصال في التعليم (TICE)

**TICE** هي توظيف TIC في التعليم والتعلم: مثل العروض التقديمية، والمحاكاة، والمنصات التعليمية، والفيديوهات القصيرة، والبحث الموجّه.

لا تعني TICE أن ينسخ المتعلم أول نتيجة يجدها؛ بل تساعده على البحث، والمقارنة، وطرح الأسئلة، ثم تقديم عمله بأسلوبه.

## 4. المعلوماتية والمنظومة المعلوماتية

**المعلوماتية (Informatique / Computer Science)** هي علم معالجة المعلومات آليًا باستعمال الأجهزة والبرامج.

مثال: عند إعداد جدول للعلامات، يدخل الأستاذ البيانات، ثم يستعمل برنامجًا لحساب المعدل وإظهار النتائج. هنا تعمل البيانات والبرنامج والحاسوب والمستخدم معًا داخل منظومة معلوماتية.

## 5. من الحاسوب الكبير إلى الأجهزة الذكية

تطورت الأجهزة بسرعة، لكن الهدف الأساسي بقي نفسه: معالجة المعلومات وحل المشكلات.

| المرحلة | مثال | ما الذي تغيّر؟ |
|---|---|---|
| الحواسيب الأولى | حواسيب كبيرة للبحث العلمي | كانت ضخمة ومكلفة وتخدم عددًا قليلًا من المستخدمين |
| الحاسوب الشخصي | حاسوب مكتبي أو محمول | أصبح الحاسوب متاحًا للدراسة والعمل والمنزل |
| الهاتف الذكي واللوح الرقمي | Android أو iPhone/iPad | صارت الخدمات الرقمية في جهاز صغير متصل بالشبكة |
| الحوسبة السحابية (Cloud Computing) | حفظ ملف في OneDrive أو Google Drive | يمكن الوصول إلى الملف من أجهزة مختلفة عبر الإنترنت مع مراعاة الخصوصية |
| الذكاء الاصطناعي | أدوات تقترح نصًا أو تلخص معلومات | أداة مساعدة تحتاج إلى تحقق بشري ولا تعوض التفكير أو المصدر الموثوق |

### أنظمة التشغيل اليوم

نظام التشغيل هو البرنامج الأساسي الذي يدير الجهاز ويتيح تشغيل التطبيقات.

- على الحواسيب: **Windows 11**، و**Linux** مثل Ubuntu، و**macOS**.
- على الهواتف والأجهزة اللوحية: **Android** و**iOS/iPadOS**.

## 6. الصحة والأمن الرقمي

### قواعد صحية (Ergonomics)

- اجلس وظهرك مستقيم وقدماك ثابتتان على الأرض.
- اجعل أعلى الشاشة قريبًا من مستوى العين.
- خذ استراحة قصيرة بانتظام وأرح عينيك.
- لا تستعمل الهاتف أو الحاسوب مدة طويلة دون حركة.

### قواعد أمنية

- استعمل كلمة مرور قوية ولا تشاركها.
- لا تفتح رابطًا أو مرفقًا مشبوهًا؛ قد يكون محاولة تصيد إلكتروني (Phishing).
- تحقق من مصدر الخبر أو الصورة قبل مشاركتها.
- اطلب مساعدة شخص بالغ أو الأستاذ عند ظهور رسالة مقلقة أو طلب غير معتاد.

## نشاط تطبيقي: خريطة تقنية لحياة التلميذ

**العمل في مجموعات من 3 أو 4 تلاميذ — 15 دقيقة**

اختر موقفًا واحدًا: إرسال واجب، البحث عن معلومة، أو مشاركة صورة مع العائلة. ثم أكمل الجدول:

| العنصر | إجابتنا |
|---|---|
| المعلومة التي نعالجها أو نرسلها | |
| الجهاز أو العتاد المستعمل | |
| البرنامج أو الخدمة المستعملة | |
| وسيلة الاتصال | |
| قاعدة صحية أو أمنية نلتزم بها | |

تشارك كل مجموعة مثالًا واحدًا وتوضح سبب اختيارها للقاعدة الصحية أو الأمنية.

## تقويم ختامي

1. اشرح الفرق بين العتاد والبرمجيات، ثم أعط مثالين لكل منهما.
2. رتّب العناصر الآتية في فئاتها: لوحة المفاتيح، Ubuntu، ملف صورة، تلميذ، Wi-Fi.
3. اذكر فائدتين لـ TIC في التعليم، وخطرًا واحدًا يمكن تفاديه بسلوك مسؤول.
4. ما المقصود بالحوسبة السحابية؟ اذكر قاعدة واحدة لحماية ملف محفوظ على الإنترنت.

### بطاقة إجابة مختصرة للأستاذ

1. العتاد أجزاء ملموسة؛ البرمجيات برامج. أمثلة: شاشة ولوحة مفاتيح / متصفح وWindows 11.
2. عتاد / برمجية / بيانات / مورد بشري / شبكة.
3. تقبل إجابات مرتبطة بالبحث أو العرض أو التواصل؛ من المخاطر التصيد أو الإفراط في وقت الشاشة أو نشر بيانات شخصية.
4. حفظ أو استعمال الملفات عبر خوادم متصلة بالإنترنت؛ تُقبل مثلًا إجابة: استعمال كلمة مرور قوية وعدم مشاركة الرابط أو البيانات الحساسة.
