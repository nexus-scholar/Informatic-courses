# Office units conventions (Units 07–14)

Decided by the teacher on 2026-11-11. Applies to the student lessons for Word (07–10), Excel (11–12) and PowerPoint (13–14).

## Reference software

- **Microsoft 365 / Office 2021** desktop apps are the reference. Mention **LibreOffice** (Writer, Calc, Impress) only in a short optional «في LibreOffice» box when the path differs a lot — never as the main path.
- No Office 2007/2010 elements: no «Office button», no «Clip Art», no task panes that no longer exist.

## Interface names: Arabic, then English — no French

- Every tab, group, button or dialog is named as in **Arabic Office**, followed by the **English** name in parentheses: «الصفحة الرئيسية (Home) › الأنماط (Styles)».
- Ribbon paths use `›` between tab, group and command: «إدراج (Insert) › جدول (Table)».
- Reference tab names: ملف (File) · الصفحة الرئيسية (Home) · إدراج (Insert) · رسم (Draw) · تصميم (Design) · تخطيط (Layout) · مراجع (References) · مراسلات (Mailings) · مراجعة (Review) · عرض (View) · صيغ (Formulas) · بيانات (Data) · انتقالات (Transitions) · حركات (Animations) · عرض الشرائح (Slide Show).
- If you are not sure of a command's exact Arabic label, describe it plainly («زر السهم الصغير أسفل يمين مجموعة الأنماط») and give the English name; do not invent a label.
- No French anywhere in the lesson, including old UI names (Accueil, Insertion, Publipostage…).

## Excel specifics

- Function names are the English ones Excel uses in English and Arabic interfaces: `SUM`, `AVERAGE`, `MIN`, `MAX`, `IF`, `AND`, `OR`, `NOT`, `COUNT`, `COUNTIF`, `ROUND`, `TODAY`.
- Argument separator: `;` in all formulas (Algerian regional settings), with one note per unit: «إذا رفض Excel الصيغة، استبدل ; بـ ,».
- Every formula shown with a sample table must give the stated result; give the sample data as a Markdown table so students can type it.
- Cell references and formulas are written as code: `=SUM(B2:D2)`.

## Lesson format

- Same structure as units 03–06 and 15–17: title, domain line, level/duration, الأهداف التعلمية, خريطة التعلم table, numbered `##` sections with `###` sub-sections, a lab activity with a task table, تقويم ختامي, بطاقة خروج 3–2–1, بطاقة إجابة مختصرة للأستاذ, معجم المصطلحات.
- Domain line follows the official progression: units 07–12 «المجال المفاهيمي الثالث: المكتبية»; units 13–14 «المجال المفاهيمي الرابع: تقنيات الويب».
- Images: keep an old screenshot only if it still matches Microsoft 365; never reference a missing image. Steps must be fully understandable without images.
- Mark content beyond the official objectives as «إثراء».
