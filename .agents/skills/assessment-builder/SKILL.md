# Assessment builder

Create assessment material only for the requested unit and duration.

1. Read the student lesson and its stated learning objectives before drafting questions.
2. Balance recall, application, and explanation. Use an observable task where a computer lab is relevant.
3. Supply a correction key and an explicit, short marking rubric. Keep the assessment suitable for 15-year-old learners and writable or performable within the stated time.
4. Separate optional enrichment from required assessment. Do not claim that an external account, online tool, or device is available.
5. If writing a lesson file, keep the assessment at its end and regenerate the corresponding HTML.

Return a compact teacher-facing summary of objectives assessed, duration, materials, and marking.
