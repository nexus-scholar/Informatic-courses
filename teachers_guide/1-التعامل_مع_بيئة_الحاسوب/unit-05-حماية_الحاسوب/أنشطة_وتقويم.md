# أنشطة وتمارين التقويم: حماية الحاسوب والبيانات

## 1. التقويم التشخيصي (بداية الحصة)

**سؤالان سريعان على السبورة، بلا تصحيح فوري:**

1. هل يمكن أن «يُخترق» حاسوب دون أن يلمسه أحد؟ كيف؟
2. ما الفرق بين فيروس الحاسوب وفيروس الزكام؟

**الهدف:** كشف التمثّلات الخاطئة (الفيروس = أي برنامج سيئ، الاختراق = لمس الجهاز) قبل البناء عليها.

## 2. التقويم التكويني (أثناء الحصة)

### النشاط الأول: من أنا؟ (تمثيل الأدوار)

يقرأ الأستاذ بطاقة، ويرفع التلاميذ اسم النوع:

| البطاقة | الإجابة |
|---|---|
| «أتنكّر في صورة لعبة مجانية، وعند تشغيلي أفتح بابًا خلفيًا للمخترق» | حصان طروادة |
| «أنتشر وحدي عبر الشبكة إلى كل أجهزة المخبر دون أن يفتح أحد ملفًا» | دودة |
| «أشفّر ملفاتك وأطلب مبلغًا ماليًا مقابل المفتاح» | برنامج فدية |
| «أسجّل كل حرف تكتبه على لوحة المفاتيح» | مسجّل مفاتيح |
| «أعرض إعلانات لا تختفي وأتتبّع تنقّلك» | برنامج إعلاني |

### النشاط الثاني: تشريح رسالة تصيد

يُعرض نص الرسالة الآتية (من الدرس)، ويُطلب من كل فوج استخراج **ثلاث علامات** وتبريرها:

> «عزيزي المستخدم، فزت بهاتف ذكي! أدخل بيانات بطاقتك خلال 24 ساعة عبر الرابط `http://prize-win.example` وإلا سيُلغى فوزك.»

**الإجابة المنتظرة:** تحية عامة، جائزة غير متوقّعة، مهلة قصيرة، رابط لا يطابق جهة معروفة، طلب بيانات بطاقة.

### النشاط الثالث: الفحص العملي

**التعليمة:** افتح **أمن Windows** ← **الحماية من الفيروسات والتهديدات** ← **خيارات الفحص** ← **فحص سريع**.

**بطاقة تسجيل:**

| المعلومة | ما تكتبه |
|---|---|
| نوع الفحص المنجز | |
| مدته التقريبية | |
| عدد التهديدات | |
| الإصدار أو آخر تحديث للتعريفات | |
| الإجراء المتخذ إن وُجد تهديد | |

**سؤال إضافي:** «لماذا نفحص مفتاح USB قبل فتحه، لا بعده؟»

## 3. التقويم الإدماجي الختامي (نهاية الوحدة)

**وضعية مشكلة (السلوك الرقمي الآمن):**

طلب منك أستاذ التاريخ بحثًا، فأعطاك زميلك مفتاح تخزين وقال: «فيه صور مفيدة، لكن حاسوبي البارحة صار ثقيلًا وتظهر فيه إعلانات غريبة، وبعض ملفاتي تغيّر امتدادها».

1. ما الخطر المحتمل في مفتاح التخزين؟
2. ما أول خطوة تقوم بها قبل فتحه؟
3. اذكر ثلاث علامات في وصف الزميل تدل على إصابة محتملة.
4. اقترح على زميلك خطة من أربع خطوات لمعالجة جهازه.
5. لماذا لا يُنصح بدفع الفدية إن ظهرت ملاحظة تشفير؟

**الإجابة المنتظرة:**

1. قد يكون مصدرًا لبرمجية خبيثة (فيروس أو دودة) تنتقل عبر وحدات التخزين.
2. فحصه بمضاد الفيروسات قبل فتح أي ملف منه.
3. بطء غير معتاد، إعلانات غريبة، تغيّر امتدادات الملفات (احتمال تشفير).
4. فصل الجهاز عن الشبكة، إبلاغ المسؤول، فحص بجهاز سليم، استرجاع من نسخة احتياطية، تغيير كلمات المرور، تحديث وفحص كامل.
5. لا ضمان للاسترجاع، والدفع يموّل الجريمة ويشجّع هجمات أخرى.

## 4. شبكة تقويم (Rubric) مختصرة

| المعيار | مبتدئ (1) | متمكن (2) | متقن (3) |
|---|---|---|---|
| تمييز الأنواع | يخلط بين الأنواع | يميّز فيروسًا من فدية | يصنّف خمسة أنواع ويبرّر |
| كشف التصيد | لا يجد علامة | يجد علامتين | يجد ثلاثًا ويقترح إجراءً |
| التطبيق العملي | يحتاج مساعدة في كل خطوة | يُجري الفحص بمساعدة جزئية | يُجري الفحص ويقرأ النتيجة |
| الاستجابة | يذكر خطوة واحدة | يذكر ثلاث خطوات | يرتّب خطة كاملة ويبرّرها |
| السلامة السلوكية | يعطّل الحماية أو يفتح مجهولًا | يتجنّب السلوك الخطر بعد التنبيه | يلتزم ويذكّر زملاءه |

---

## 5. امتدادات وأنشطة إثرائية

- **ملصق توعوي للمخبر:** ثلاث قواعد للحماية بخط كبير، يُعلّق قرب الحواسيب.
- **تحقيق مصغّر:** يحضر كل فوج خبرًا حديثًا عن هجوم إلكتروني (بإشراف الأستاذ)، ويستخرج منه: نوع الهجوم، القناة، والضرر.
- **بطاقة «قبل أن أضغط»:** خمسة أسئلة يسألها التلميذ لنفسه قبل فتح رابط أو مرفق.
