# أنشطة وتمارين التقويم: الشبكة المحلية (LAN)

## 1. التقويم التكويني (أثناء الحصص)

### النشاط الأول: صنّف شبكتك (الحصة 1 — 5 دقائق)

- **التعليمة:** صنّف كل شبكة حسب امتدادها (PAN / LAN / MAN / WAN) ووسيلة ربطها (سلكية / لاسلكية):
  1. هاتفك متصل بسماعة لاسلكية.
  2. هاتفك وحاسوبك متصلان بعلبة المنزل.
  3. حواسيب مخبر الإعلام الآلي.
  4. شبكة تربط مقرّات بلدية في مدينة واحدة.
  5. الإنترنت.
- **الهدف:** التصنيف حسب معيارين معًا.
- **الإجابة المنتظرة:** 1) PAN لاسلكية (بلوتوث)؛ 2) LAN لاسلكية غالبًا (Wi-Fi)؛ 3) LAN سلكية غالبًا؛ 4) MAN (ألياف بصرية غالبًا)؛ 5) WAN تجمع كل الوسائل.

### النشاط الثاني: من يسلّم الرسالة؟ (الحصة 2 — 5 دقائق)

- **التعليمة:** أكمل الجدول بـ Hub أو Switch أو Router:

| الوصف | الجهاز |
|---|---|
| يرسل البيانات إلى كل الأجهزة المتصلة به | |
| يرسل البيانات إلى الجهاز المقصود فقط بالاعتماد على عنوان MAC | |
| يربط شبكة المخبر بالإنترنت | |
| جهاز قديم لم يعد يُستعمل في الشبكات الحديثة | |
| موجود داخل العلبة المنزلية مع المودم ونقطة الوصول | |

- **الإجابة المنتظرة:** Hub — Switch — Router — Hub — Router (ويوجد أيضًا Switch داخل العلبة، تُقبل الإجابتان مع التبرير).

### النشاط الثالث: سلكي أم لاسلكي؟ (الحصة 1 أو 3 — 4 دقائق)

- **التعليمة:** انظر إلى حاسوبك والأسلاك المتصلة به. هل هو مرتبط بالشبكة سلكيًا أم لاسلكيًا؟ ما الدليل؟ ثم اذكر ميزة وعيبًا لهذا النوع.
- **الإجابة المنتظرة:** كابل في منفذ RJ45 وأيقونة الشاشة في شريط المهام (سلكي)، أو أيقونة موجات Wi-Fi (لاسلكي). سلكي: مستقر وسريع / مقيّد المكان. لاسلكي: حرية التنقل / يتأثر بالجدران ويحتاج حماية بكلمة مرور.

### النشاط الرابع: بطاقة هوية حاسوبي (الحصة 3 — 10 دقائق)

- **التعليمة:** املأ البطاقة:

| العنصر | قيمته على حاسوبي | أين وجدته؟ |
|---|---|---|
| اسم الحاسوب | | |
| مجموعة العمل | | |
| عنوان IPv4 | | |
| العنوان الفعلي (MAC) | | |
| نوع ملف تعريف الشبكة (خاصة / عامة) | | |

- **الإجابة المنتظرة:** الاسم من الإعدادات ← النظام ← حول؛ مجموعة العمل عادة `WORKGROUP`؛ IPv4 وMAC من `ipconfig /all`؛ النوع **خاصة** في المخبر. يقارن التلميذ عنوانه بعنوان زميله: البداية نفسها (مثل `192.168.1.`) والرقم الأخير مختلف.

### النشاط الخامس: اقرأ أم اكتب؟ (الحصة 4 — 15 دقيقة)

- **التعليمة:**
  1. افتح المجلد المشترك على حاسوب الأستاذ بطريقتين: نافذة **الشبكة**، ثم كتابة `\\PROF-PC\Cours`.
  2. انسخ ملف التمرين إلى سطح مكتبك، ثم حاول حذفه من المجلد `Cours`. ماذا يحدث؟
  3. ضع ملفًا يحمل اسمك في المجلد `Remise`. ماذا يحدث؟ فسّر الفرق.
- **الهدف:** المشاركة واكتشاف مورد داخل مجموعة العمل (تقويم رسمي).
- **الإجابة المنتظرة:** الحذف من `Cours` مرفوض (إذن **قراءة**)؛ الكتابة في `Remise` تنجح (إذن **قراءة/كتابة**). إن لم يظهر حاسوب الأستاذ في نافذة الشبكة، فالكتابة المباشرة للعنوان تكفي.

## 2. التقويم الإدماجي الختامي (نهاية الوحدة)

**الوضعية (مكتب ترجمة صغير):**
قرّر ثلاثة شبّان فتح مكتب ترجمة. اشتروا 3 حواسيب مكتبية وحاسوبًا محمولًا وطابعة واحدة، واشتركوا في الإنترنت بعلبة من مزوّد الخدمة. طلبوا منك أن يتمكن الجميع من الطباعة ومن تبادل الوثائق دون مفتاح USB، وأن يصل المحمول إلى الشبكة من أي مكان في المكتب.

**المطلوب:**

| المهمة | التعليمة | النقاط |
|---|---|---|
| 1 | ما نوع هذه الشبكة حسب الامتداد (LAN أم WAN)؟ وحسب العلاقة الوظيفية؟ برّر. | 2 |
| 2 | اقترح نوع الاتصال (سلكي أم لاسلكي) لكل من: الحواسيب المكتبية، المحمول، الطابعة. | 2 |
| 3 | اذكر العتاد اللازم للربط السلكي (ثلاثة عناصر على الأقل)، وبيّن لماذا تختار المحوّل لا الموزّع. | 2 |
| 4 | ارسم الشبكة بطوبولوجيا النجمة، واذكر دور العلبة (الموجّه). | 2 |
| 5 | يريد المسؤول مشاركة مجلد «القوالب» دون أن يعدّله أحد، ومجلد «الترجمات المنجزة» يضع فيه الجميع أعمالهم. أي إذن لكل مجلد؟ ولماذا لا يشارك القرص `D:` كاملًا؟ | 2 |

**المجموع:** 10 نقاط.

**عناصر الإجابة:**

1. **LAN** (مكتب واحد في موقع واحد)؛ **ند للند** (مجموعة عمل، لا خادم مركزي).
2. المكتبية: **سلكي** (ثابتة، مستقرة)؛ المحمول: **لاسلكي** (تنقّل)؛ الطابعة: **سلكي** يفضَّل أو Wi-Fi.
3. بطاقات الشبكة (مدمجة غالبًا)، كابلات إيثرنت Cat 5e/Cat 6 بوصلات RJ45، **محوّل** (أو منافذ العلبة إن كفت)، والعلبة/الموجّه للإنترنت. المحوّل يرسل للجهاز المقصود فقط فلا تزدحم الشبكة، والموزّع قديم يرسل للجميع.
4. رسم نجمي: كل جهاز بكابل مستقل إلى المحوّل، والمحوّل متصل بالعلبة؛ المحمول متصل بنقطة الوصول (Wi-Fi العلبة). العلبة تربط الشبكة المحلية بالإنترنت.
5. «القوالب»: **قراءة**؛ «الترجمات المنجزة»: **قراءة/كتابة** (تغيير). مشاركة القرص كاملًا تكشف كل محتواه وتعرّضه للحذف والعدوى؛ نشارك المجلد المحدّد فقط (مبدأ أقل صلاحية).

## 3. شبكة التقويم (Rubric) للجانب التطبيقي

| المعيار | ممتاز (2) | مقبول (1) | غير مكتمل (0) |
|---|---|---|---|
| تحديد العتاد والطوبولوجيا | يسمّي كل مكونات شبكة المخبر ويرسمها نجمية | رسم صحيح مع نقص في التسمية | رسم غير نجمي أو بلا تسمية |
| العنونة | يجد IP والاسم ومجموعة العمل ويشرح الفرق IP/MAC | يجد القيم دون شرح | لا يجدها دون توجيه |
| الوصول إلى مورد مشترك | يصل بطريقتين (نافذة الشبكة + `\\اسم\مجلد`) | بطريقة واحدة | لا يصل |
| الأذونات | يفسّر الفرق بين القراءة والكتابة بعد التجربة | ينجز دون تفسير | يخلط بينهما |
| الأمان | لا يغيّر الإعدادات ويذكر قاعدة الشبكة العامة | تنبيه بسيط | يعبث بإعدادات الشبكة |

## 4. نشاط إثرائي (للمنزل أو للمتفوقين)

1. **شبكة منزلي:** دوّن عدد الأجهزة المتصلة بعلبة منزلك، وصنّفها سلكي/لاسلكي، ثم اقترح قاعدتين لحماية شبكة Wi-Fi المنزل. *(أمثلة: كلمة مرور قوية، تشفير WPA2/WPA3، تغيير كلمة مرور إدارة العلبة الافتراضية، عدم إعطاء كلمة المرور للغرباء.)*
2. **عنوان IP:** على هاتفك، ابحث في إعدادات Wi-Fi عن عنوان IP. هل يشبه عنوان حاسوبك في المنزل؟ لماذا؟ *(نعم في البداية، لأنهما في الشبكة المحلية نفسها؛ الرقم الأخير مختلف.)*
3. **محاكاة:** في Cisco Packet Tracer، اربط حاسوبين بمحوّل واختبر الاتصال بينهما. *(اختياري، يتطلب التسجيل المجاني في أكاديمية Cisco.)*
