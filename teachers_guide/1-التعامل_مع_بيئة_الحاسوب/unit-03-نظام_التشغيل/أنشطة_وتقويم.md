# أنشطة وتمارين التقويم: نظام التشغيل

## 1. التقويم التكويني (أثناء الحصص)

### النشاط الأول: من يفعل ماذا؟ (الحصة 1 — 5 دقائق)

- **التعليمة:** اربط كل موقف بوظيفة نظام التشغيل المناسبة:
  1. تُدخل ذاكرة USB فتظهر في مستكشف الملفات.
  2. تستمع إلى الموسيقى وأنت تكتب بحثك.
  3. تغلق لعبة ثقيلة فيصبح الجهاز أسرع.
  4. تحفظ ملفًا في مجلد «دروسي» على القرص `D:`.
- **الهدف:** ربط الوظائف بمواقف يومية (تقويم رسمي: أذكر أهم وظائف نظام التشغيل).
- **الإجابة المنتظرة:** 1 إدارة الأجهزة الملحقة (برامج التعريف)؛ 2 إدارة المعالج / تعدد المهام؛ 3 إدارة الذاكرة؛ 4 إدارة الملفات والتخزين.

### النشاط الثاني: صحّح الكتاب القديم (الحصة 1 — 4 دقائق)

- **التعليمة:** في كتاب 2015 وردت قائمة «أنظمة الهواتف»: Android، BlackBerry OS، iOS، Windows Phone، Mac OS. صحّحها لتناسب اليوم.
- **الإجابة المنتظرة:** تبقى Android وiOS (ويضاف iPadOS للألواح)؛ BlackBerry OS وWindows Phone متوقفان؛ Mac OS (اليوم macOS) نظام حواسيب لا هواتف.

### النشاط الثالث: الإقلاع الأول (الحصة 2 — 8 دقائق)

- **التعليمة:**
  1. رتّب: حفظ وخروج — الدخول إلى برنامج الإعداد — إدخال ذاكرة USB — وضع USB أولًا في ترتيب الإقلاع — تشغيل الجهاز — فتح قسم Boot.
  2. في VirtualBox، افتح إعدادات الآلة ← النظام، واكتب ترتيب الإقلاع الظاهر. من أين ستُقلع الآلة أول مرة؟ ولماذا تُقلع من القرص الافتراضي بعد التثبيت؟
- **الهدف:** تقويم رسمي: كيفية تنفيذ الإقلاع الأول في برنامج الإعداد.
- **الإجابة المنتظرة:** إدخال USB ← تشغيل الجهاز ← الدخول إلى الإعداد (Del أو F2 حسب الصانع) ← Boot ← USB أولًا ← حفظ وخروج. الآلة تُقلع من صورة ISO لأن القرص الافتراضي فارغ لا نظام فيه؛ بعد التثبيت يصبح فيه نظام، وتُفصل صورة ISO عادة.

### النشاط الرابع: تقسيم أم تهيئة؟ (الحصة 3 — 5 دقائق)

- **التعليمة:** اكتب أمام كل عملية: **تقسيم** أو **تهيئة**:
  1. جعل قرص بحجم 1 TB جزأين: `C:` و`D:`.
  2. اختيار exFAT لذاكرة USB.
  3. إنشاء جدول GPT على قرص جديد.
  4. محو ذاكرة USB بسرعة لاستعمالها من جديد.
  5. تصغير `C:` لإنشاء جزء لنظام Linux.
- **الإجابة المنتظرة:** 1 تقسيم؛ 2 تهيئة؛ 3 تقسيم؛ 4 تهيئة (سريعة)؛ 5 تقسيم.

### النشاط الخامس: بطاقة توثيق المراحل (الحصة 4 — أثناء التثبيت)

| رقم | اسم المرحلة كما فهمتها | ما اخترته | لماذا؟ |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| … | | | |

- **التعليمة:** املأ سطرًا لكل شاشة جديدة في المثبّت.
- **مؤشر النجاح:** ست مراحل على الأقل بالترتيب الصحيح، منها إعداد القرص وإنشاء الحساب.

## 2. التقويم الإدماجي الختامي (نهاية الوحدة)

**الوضعية:** اشترى أخوك الأكبر قرص SSD جديدًا فارغًا لحاسوبه القديم بعد أن تعطّل قرصه، وطلب منك المساعدة في تثبيت Windows 11. معه ذاكرة USB بسعة 16 GB فيها صور العائلة، وحاسوب آخر سليم متصل بالإنترنت.

**المطلوب:**

| المهمة | التعليمة | النقاط |
|---|---|---|
| 1 | ما الذي يجب فعله بصور العائلة قبل تحويل الذاكرة إلى وسيط تثبيت؟ ولماذا؟ | 1 |
| 2 | اذكر شرطين من شروط Windows 11 يجب التحقق منهما في الحاسوب القديم | 2 |
| 3 | اشرح كيف تجعل الحاسوب يُقلع من ذاكرة USB (طريقتان) | 2 |
| 4 | رتّب ست مراحل يقترحها برنامج الإعداد، من اختيار اللغة إلى إنشاء الحساب | 3 |
| 5 | القرص الجديد فارغ: هل يحتاج إلى تقسيم أم تهيئة أم كليهما؟ بأي ترتيب؟ وما نظام الملفات المتوقع لتجزئة Windows؟ | 2 |

**المجموع:** 10 نقاط.

**عناصر الإجابة:**

1. نسخها احتياطيًا على الحاسوب الآخر أو وسيط آخر، لأن تحضير ذاكرة التثبيت يمحو محتواها.
2. أي اثنين: UEFI مع Secure Boot، TPM 2.0، معالج متوافق، 4 GB RAM على الأقل، 64 GB تخزين على الأقل.
3. قائمة الإقلاع بمفتاح الصانع (F12، F11، F9، Esc...)؛ أو برنامج الإعداد (Del، F2...) ← Boot ← USB أولًا ← حفظ وخروج.
4. اللغة والمنطقة ← (مفتاح المنتج أو تخطيه) ← الإصدار ← الترخيص ← تثبيت مخصّص ← اختيار موضع التثبيت/التجزئة ← نسخ الملفات وإعادة التشغيل ← المنطقة ولوحة المفاتيح ← الشبكة ← الحساب. تُمنح النقاط الثلاث لست مراحل مرتبة صحيحة.
5. كلاهما: **التقسيم أولًا** (جدول GPT وتجزئات، ينجزه برنامج الإعداد تلقائيًا عند اختيار المساحة غير المخصّصة) ثم **التهيئة** بنظام **NTFS**.

## 3. شبكة التقويم (Rubric)

| المعيار | ممتاز (2) | مقبول (1) | غير مكتمل (0) |
|---|---|---|---|
| وظائف النظام | أربع وظائف بأمثلة صحيحة | وظيفتان أو بلا أمثلة | خلط بين النظام والتطبيقات |
| الإقلاع الأول | خطوات مرتبة + يعرف أن المفتاح يختلف | خطوات ناقصة | لا يعرف الهدف من الإجراء |
| التقسيم / التهيئة | يميّز ويرتّب ويحذّر من المحو | يميّز دون ترتيب | يخلط بينهما |
| مراحل التثبيت | ترتيب صحيح لست مراحل أو أكثر | ترتيب صحيح لأربع | ترتيب عشوائي |
| السلامة | نسخ احتياطي + عمل داخل الآلة الافتراضية فقط | يحتاج تذكيرًا | يخاطر بالحاسوب الحقيقي |

## 4. نشاط إثرائي (للمنزل)

1. على حاسوب المنزل (بإذن الأهل): افتح **الإعدادات ← النظام ← حول** واكتب اسم نظام التشغيل وإصداره وحجم RAM. *(للملاحظة فقط.)*
2. على هاتفك: ابحث في الإعدادات عن اسم نظام التشغيل وإصداره، وعن مساحة التخزين المستعملة.
3. ابحث: ما مفتاح الدخول إلى برنامج الإعداد ومفتاح قائمة الإقلاع في حاسوب من علامة تجارية تختارها؟ اذكر مصدر معلومتك (موقع الصانع).
4. **(إثراء)** لماذا تحتوي معظم ذاكرات USB الجديدة على نظام الملفات FAT32 أو exFAT وليس NTFS؟ *(الإجابة: للتوافق مع أكبر عدد من الأجهزة: هواتف، تلفاز، سيارات، حواسيب Mac.)*
