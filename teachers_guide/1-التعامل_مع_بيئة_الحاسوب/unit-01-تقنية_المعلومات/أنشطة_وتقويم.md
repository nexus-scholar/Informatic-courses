# أنشطة وتقويم الوحدة 01: تقنية المعلومات والتطور التكنولوجي

## بطاقة استعمال

| العنصر | البيان |
|---|---|
| الزمن | 15 دقيقة للنشاط الجماعي، و10 دقائق للتقويم الختامي |
| التنظيم | مجموعات من 3 أو 4 تلاميذ، ثم مناقشة جماعية |
| الوسائل | سبورة أو بطاقات ورقية؛ حاسوب القاعة اختياري |
| الأهداف المقوَّمة | مكوّنات TIC، العتاد والبرمجيات والبيانات والشبكات، الاستعمال المسؤول |

## 1. تقويم تكويني أثناء الدرس

### النشاط 1: صنّف المكوّنات

اعرض الكلمات الآتية: **لوحة مفاتيح، Windows 11، ملف صورة، تلميذ، Wi-Fi، متصفح**.

يضع التلاميذ كل كلمة في فئة واحدة: عتاد، برمجيات، بيانات، مورد بشري، أو شبكة.

**التصحيح:** لوحة مفاتيح/عتاد؛ Windows 11 والمتصفح/برمجيات؛ ملف صورة/بيانات؛ تلميذ/مورد بشري؛ Wi-Fi/شبكة.

### النشاط 2: رسالة آمنة

اعرض موقفًا: «وصلت إلى تلميذ رسالة تطلب منه فتح رابط وإدخال كلمة مروره للحصول على لعبة مجانية».

يذكر كل فريق سلوكين آمنين مناسبين.

**إجابات مقبولة:** عدم فتح الرابط، عدم مشاركة كلمة المرور، التحقق من المرسل، وإخبار الأستاذ أو شخص بالغ.

## 2. نشاط إدماجي: خريطة تقنية لحياة التلميذ

يختار كل فريق موقفًا واحدًا: إرسال واجب، البحث عن معلومة، أو مشاركة صورة مع العائلة. ثم يملأ الجدول:

| العنصر | إجابة الفريق |
|---|---|
| المعلومة المتبادلة | |
| العتاد المستعمل | |
| البرنامج أو الخدمة | |
| وسيلة الاتصال | |
| قاعدة صحية أو أمنية | |

**معيار النجاح:** يحدد الفريق العناصر الخمسة بدقة، ويبرر قاعدة واحدة مرتبطة فعلًا بالموقف.

## 3. تقويم ختامي فردي

1. اشرح الفرق بين العتاد والبرمجيات، ثم أعط مثالين لكل منهما. **(4 ن)**
2. ما المقصود بالحوسبة السحابية؟ اذكر فائدة واحدة واحتياطًا واحدًا عند حفظ ملف عبر الإنترنت. **(3 ن)**
3. اذكر فائدتين لـTIC في التعليم، وخطرًا واحدًا يمكن تفاديه بسلوك مسؤول. **(3 ن)**

### شبكة تصحيح مختصرة

| المعيار | النقاط |
|---|---:|
| تعريف صحيح للعتاد والبرمجيات مع أمثلة مناسبة | 4 |
| فهم أن الملف يمكن الوصول إليه عبر الإنترنت مع ذكر فائدة واحتياط واقعي | 3 |
| فائدتان واضحتان وخطر واحد مع سلوك وقائي | 3 |

## 4. نشاط منزلي اختياري

اطلب من التلميذ أن يسأل أحد أفراد أسرته عن خدمة رقمية مفيدة (حجز، تواصل، دراسة، أو دفع). يكتب في خمسة أسطر: الخدمة، نوع المعلومة، الجهاز المستعمل، وفائدة واحدة أو قاعدة أمان واحدة.

لا يُطلب من التلاميذ إنشاء حسابات جديدة أو مشاركة معلومات شخصية.
