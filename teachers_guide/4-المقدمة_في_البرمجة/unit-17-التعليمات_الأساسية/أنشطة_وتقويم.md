# أنشطة وتمارين التقويم: التعليمات الأساسية

## 1. التقويم التكويني (أثناء الحصص)

### النشاط الأول: علب المتغيرات (دون حاسوب — الحصة 1، 10 دقائق)

- **التجهيز:** ثلاث علب (أو أكواب) مكتوب عليها `a` و`b` و`tmp`، وبطاقات أرقام.
- **التعليمة:** ينفّذ ثلاثة تلاميذ أمام القسم التعليمات التي يقرؤها زميلهم سطرًا سطرًا: `a ← 4`، `b ← 9`، ثم محاولة التبادل بـ `a ← b` و`b ← a`. يلاحظ القسم ضياع القيمة 4، ثم يُعاد النشاط بالمتغير `tmp`.
- **الهدف:** جعل محو القيمة القديمة في الإسناد محسوسًا، وتبرير الحاجة إلى المتغير المؤقت.
- **الإجابة المنتظرة:** بعد المحاولة الأولى `a = 9` و`b = 9`؛ بعد الثانية `a = 9` و`b = 4`.

### النشاط الثاني: نص أم قيمة؟ (الحصة 2، 5 دقائق)

- **التعليمة:** مع `x ← 4`، توقّع ما يظهر لكل من: `Write("x")`، `Write(x)`، `Write(x + 1)`، `Write("x + 1")`، `Write("x = ", x)`. ثم تحقق في Algobox.
- **الإجابة المنتظرة:** `x`، `4`، `5`، `x + 1`، `x = 4`.

### النشاط الثالث: الحلقة البشرية (دون حاسوب — الحصة 5، 5 دقائق)

- **التعليمة:** تلميذ «حاسوب» يحمل بطاقة `S = 0`. يقرأ الأستاذ `For i ← 1 To 5 Do S ← S + i EndFor`، ويرفع تلميذ آخر بطاقة `i` في كل دورة. يكتب القسم القيم المتتالية لـ `S`.
- **الإجابة المنتظرة:** 1، 3، 6، 10، 15.

### النشاط الرابع: من المخطط إلى الشبه-رمز (اختياري، Flowgorithm)

- **التعليمة:** ارسم في Flowgorithm (المستعمل في الوحدة 15) مخطط «ناجح أم راسب» ثم مخطط مجموع 1 إلى 5، ونفّذهما. اكتب الشبه-رمز المقابل لكل مخطط في الكراس.
- **ملاحظة:** نافذة الشفرة المصدرية (Source Code Viewer) في Flowgorithm يمكن أن تعرض المقابل بلغة Python، وهي فرصة لإثراء المتفوقين؛ لكن الصيغة المعتمدة تبقى الشبه-رمز الرسمي.

### النشاط الخامس: صيّاد الأخطاء (الحصة 7، 10 دقائق)

- **التعليمة:** في الخوارزمية التالية أربعة أخطاء. جدها وصحّحها.

```text
Algorithm AverageOfThree
Var
    i, grade, S : Real
Begin
    For i ← 1 To 3 Do
        S ← 0
        Read(grade)
        S = S + grade
    EndFor
    Write("S / 3")
End
```

- **الإجابة المنتظرة:** (1) `i` عدّاد فنوعه `Integer`؛ (2) `S ← 0` تُنقل قبل الحلقة؛ (3) `S = S + grade` تُصحَّح إلى `S ← S + grade`؛ (4) `Write("S / 3")` تُظهر النص حرفيًا، والصحيح `Write(S / 3)` أو `Write("المعدل: ", S / 3)`.

### النشاط السادس (إثراء Python): صيّاد الأخطاء في Python

```python
age = input(كم عمرك؟)
if age > 18
print("أنت بالغ")
```

- **الأخطاء الأربعة:** (1) غياب علامتي التنصيص حول نص السؤال؛ (2) غياب النقطتين `:` بعد الشرط؛ (3) غياب الإزاحة قبل `print`؛ (4) غياب التحويل `int()`: `input()` تُرجع نصًا، والمقارنة `age > 18` تتوقف بخطأ `TypeError` في Python 3. هذا خطأ أساسي لا «متقدم».
- **التصحيح:**

```python
age = int(input("كم عمرك؟ "))
if age >= 18:
    print("أنت بالغ")
```

> **ملاحظة:** الشرط الأصلي `age > 18` يستثني من عمره 18 سنة؛ اسأل التلاميذ أيهما المقصود (`>` أم `≥`): إنه درس القيمة الحدّية نفسه.

## 3. التقويم الإدماجي الرسمي: المشروع المصغر «إحصائيات القسم»

**الوضعية والمطلوب:** في القسم 9 من درس التلميذ. **المدة:** حصة تطبيقية كاملة (الحصة 8). **العمل:** فردي.

### الحل النموذجي

```text
Algorithm ClassStats
Var
    n, i, passCount : Integer
    grade, total, avg, best : Real
Begin
    Write("عدد التلاميذ:")
    Read(n)
    total ← 0
    passCount ← 0
    best ← 0
    For i ← 1 To n Do
        Write("نقطة التلميذ ", i, ":")
        Read(grade)
        total ← total + grade
        If grade ≥ 10 Then
            passCount ← passCount + 1
        EndIf
        If grade > best Then
            best ← grade
        EndIf
    EndFor
    avg ← total / n
    Write("الناجحون: ", passCount, " من ", n)
    Write("معدل القسم: ", avg)
    Write("أحسن نقطة: ", best)
End
```

### جدول التتبع (n = 5، النقاط 12، 8.5، 15، 9، 17.5)

| الدورة | i | grade | total | `grade ≥ 10` | passCount | `grade > best` | best |
|---|---|---|---|---|---|---|---|
| قبل الحلقة | ؟ | ؟ | 0 | | 0 | | 0 |
| 1 | 1 | 12 | 12 | `True` | 1 | `12 > 0`: `True` | 12 |
| 2 | 2 | 8.5 | 20.5 | `False` | 1 | `8.5 > 12`: `False` | 12 |
| 3 | 3 | 15 | 35.5 | `True` | 2 | `15 > 12`: `True` | 15 |
| 4 | 4 | 9 | 44.5 | `False` | 2 | `9 > 15`: `False` | 15 |
| 5 | 5 | 17.5 | 62 | `True` | 3 | `17.5 > 15`: `True` | 17.5 |

بعد الحلقة: `avg = 62 / 5 = 12.4`. الشاشة: `الناجحون: 3 من 5` ثم `معدل القسم: 12.4` ثم `أحسن نقطة: 17.5`.

### نقاط تستحق النقاش عند التصحيح

- **قيمة `best` الابتدائية:** 0 مقبولة لأن النقاط بين 0 و20. حل أعمّ: إسناد أول نقطة مقروءة إلى `best`. يُقبل الحلّان.
- **القسمة على صفر:** إن أدخل المستخدم `n = 0` فـ `total / n` مستحيلة. الحل المتقدم: `While n < 1 Do Read(n) EndWhile` بعد القراءة الأولى. لا يُعاقب غيابه، ويكافأ وجوده (نقطة إضافية).
- **اختيار الحلقة:** `For` هي الأنسب لأن عدد التلاميذ يُقرأ قبل الحلقة فيصبح معروفًا. يُقبل `While` بعدّاد صحيح.

### شبكة التصحيح (20 نقطة)

| المعيار | ممتاز | مقبول | غير مكتمل | النقاط |
|---|---|---|---|---|
| التحليل: المدخلات والمخرجات والأنواع | كاملة وصحيحة | نقص بسيط في الأنواع | غائب | 2 |
| الهيكل والتصريح (`Algorithm`، `Var`، `Begin`، `End`) | كامل | متغير غير مصرّح به | غائب | 2 |
| القراءة والكتابة (رسائل واضحة، نص/قيمة) | صحيحة كلها | خلط في موضع واحد | خلط متكرر | 2 |
| الحلقة (اختيار مبرّر، حدود صحيحة، `EndFor`) | صحيحة ومبرّرة | صحيحة دون تبرير | خاطئة | 4 |
| المجمّع والعدّاد (التهيئة قبل الحلقة) | الاثنان صحيحان | واحد صحيح | لا شيء | 3 |
| الشروط (`≥ 10`، أحسن نقطة، `EndIf`) | الشرطان صحيحان | شرط واحد | لا شيء | 3 |
| جدول التتبع بالمثال التجريبي | صحيح كامل | خطأ في دورة واحدة | غائب | 2 |
| التنفيذ في Algobox | يعمل ويعطي النتائج المنتظرة | يعمل بنتيجة ناقصة | لا يعمل | 2 |
| **المجموع** | | | | **20** |

> **دون حواسيب:** يُحوّل معيار «التنفيذ في Algobox» إلى تتبّع ثانٍ بمدخلات يختارها الأستاذ (مثلًا n = 3: النقاط 10، 10، 4 ← `الناجحون: 2 من 3`، `معدل القسم: 8`، `أحسن نقطة: 10`).

## 4. وضعية بديلة (للمعالجة أو للفوج الثاني): الصراف الآلي

**الوضعية:** رصيد حساب 5000 دج. يكتب المستخدم المبلغ الذي يريد سحبه، ويكرّر ذلك حتى يكتب 0. إن كان المبلغ أكبر من الرصيد تظهر `الرصيد غير كافٍ`، وإلا يُطرح المبلغ ويظهر الرصيد الجديد.

**مثال:** المدخلات `2000`، `4000`، `1500`، `0` يُعطي `الرصيد الجديد: 3000` ثم `الرصيد غير كافٍ` ثم `الرصيد الجديد: 1500` ثم `إلى اللقاء`.

```text
Algorithm CashMachine
Var
    balance, amount : Real
Begin
    balance ← 5000
    Write("المبلغ (0 للإنهاء):")
    Read(amount)
    While amount ≠ 0 Do
        If amount > balance Then
            Write("الرصيد غير كافٍ")
        Else
            balance ← balance - amount
            Write("الرصيد الجديد: ", balance)
        EndIf
        Write("المبلغ (0 للإنهاء):")
        Read(amount)
    EndWhile
    Write("إلى اللقاء")
End
```

| الدورة | amount | `amount ≠ 0` | `amount > balance` | balance | الشاشة |
|---|---|---|---|---|---|
| قبل الحلقة | 2000 | | | 5000 | |
| 1 | 2000 | `True` | `False` | 3000 | `الرصيد الجديد: 3000` |
| 2 | 4000 | `True` | `True` | 3000 | `الرصيد غير كافٍ` |
| 3 | 1500 | `True` | `False` | 1500 | `الرصيد الجديد: 1500` |
| — | 0 | `False` (خروج) | | 1500 | `إلى اللقاء` |

> هذه الوضعية تستعمل `While` لأن عدد العمليات غير معروف مسبقًا، وهي مكمّلة للمشروع المصغر الذي يستعمل `For`. **للمتفوقين:** رفض المبالغ السالبة بشرط مركّب.

## 5. نشاط إثرائي (للمنزل)

1. **سؤال تفكير:** حوّل خوارزمية مجموع 1 إلى 100 من `For` إلى `While`. ما التعليمتان اللتان يجب أن تضيفهما بنفسك؟ *(الإجابة: `i ← 1` قبل الحلقة و`i ← i + 1` داخلها، مع الشرط `i ≤ 100`.)*
2. **لعبة التخمين:** الحاسوب يحفظ عددًا سريًا (ثابت `SECRET = 37`)، والمستخدم يخمّن حتى يجده، وفي كل مرة يظهر `أكبر` أو `أصغر` (العدد السري أكبر أو أصغر من التخمين)، وفي النهاية عدد المحاولات. مثال: `50`، `25`، `37` يُعطي `أصغر`، `أكبر`، `وجدته في 3 محاولات`.
3. **Python (اختياري):** اكتب المشروع المصغر بلغة Python باستعمال `for` و`float(input())`، وقارن عدد الأسطر مع الشبه-رمز.
