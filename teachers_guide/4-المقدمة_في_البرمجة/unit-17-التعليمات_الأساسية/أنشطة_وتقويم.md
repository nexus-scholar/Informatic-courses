# أنشطة وتمارين التقويم: التعليمات الأساسية

## 1. التقويم التكويني (أثناء الحصص)

### النشاط الأول: علب المتغيرات (دون حاسوب — الحصة 1، 10 دقائق)

- **التجهيز:** ثلاث علب (أو أكواب) مكتوب عليها `a` و`b` و`tmp`، وبطاقات أرقام.
- **التعليمة:** ينفّذ ثلاثة تلاميذ أمام القسم التعليمات التي يقرؤها زميلهم سطرًا سطرًا: `a ← 4`، `b ← 9`، ثم محاولة التبادل بـ `a ← b` و`b ← a`. يلاحظ القسم ضياع القيمة 4، ثم يُعاد النشاط بالمتغير `tmp`.
- **الهدف:** جعل محو القيمة القديمة في الإسناد محسوسًا، وتبرير الحاجة إلى المتغير المؤقت.
- **الإجابة المنتظرة:** بعد المحاولة الأولى `a = 9` و`b = 9`؛ بعد الثانية `a = 9` و`b = 4`.

### النشاط الثاني: نص أم قيمة؟ (الحصة 2، 5 دقائق)

- **التعليمة:** مع `x ← 4`، توقّع ما يظهر لكل من: `Ecrire("x")`، `Ecrire(x)`، `Ecrire(x + 1)`، `Ecrire("x + 1")`، `Ecrire("x = ", x)`. ثم تحقق في Algobox.
- **الإجابة المنتظرة:** `x`، `4`، `5`، `x + 1`، `x = 4`.

### النشاط الثالث: الحلقة البشرية (دون حاسوب — الحصة 5، 5 دقائق)

- **التعليمة:** تلميذ «حاسوب» يحمل بطاقة `S = 0`. يقرأ الأستاذ `Pour i de 1 à 5 Faire S ← S + i FinPour`، ويرفع تلميذ آخر بطاقة `i` في كل دورة. يكتب القسم القيم المتتالية لـ `S`.
- **الإجابة المنتظرة:** 1، 3، 6، 10، 15.

### النشاط الرابع: من المخطط إلى الشبه-رمز (اختياري، Flowgorithm)

- **التعليمة:** ارسم في Flowgorithm (المستعمل في الوحدة 15) مخطط «ناجح أم راسب» ثم مخطط مجموع 1 إلى 5، ونفّذهما. اكتب الشبه-رمز المقابل لكل مخطط في الكراس.
- **ملاحظة:** نافذة الشفرة المصدرية (Source Code Viewer) في Flowgorithm يمكن أن تعرض المقابل بلغة Python، وهي فرصة لإثراء المتفوقين؛ لكن الصيغة المعتمدة تبقى الشبه-رمز الرسمي.

### النشاط الخامس: صيّاد الأخطاء (الحصة 7، 10 دقائق)

- **التعليمة:** في الخوارزمية التالية أربعة أخطاء. جدها وصحّحها.

```text
Algorithme Moyenne_Trois
Var
    i, note, S : Réel
Début
    Pour i de 1 à 3 Faire
        S ← 0
        Lire(note)
        S = S + note
    FinPour
    Ecrire("S / 3")
Fin
```

- **الإجابة المنتظرة:** (1) `i` عدّاد فنوعه `Entier`؛ (2) `S ← 0` تُنقل قبل الحلقة؛ (3) `S = S + note` تُصحَّح إلى `S ← S + note`؛ (4) `Ecrire("S / 3")` تُظهر النص حرفيًا، والصحيح `Ecrire(S / 3)` أو `Ecrire("Moyenne : ", S / 3)`.

### النشاط السادس (إثراء Python): صيّاد الأخطاء في Python

```python
age = input(كم عمرك؟)
if age > 18
print("أنت بالغ")
```

- **الأخطاء الأربعة:** (1) غياب علامتي التنصيص حول نص السؤال؛ (2) غياب النقطتين `:` بعد الشرط؛ (3) غياب الإزاحة قبل `print`؛ (4) غياب التحويل `int()`: `input()` تُرجع نصًا، والمقارنة `age > 18` تتوقف بخطأ `TypeError` في Python 3. هذا خطأ أساسي لا «متقدم».
- **التصحيح:**

```python
age = int(input("كم عمرك؟ "))
if age >= 18:
    print("أنت بالغ")
```

> **ملاحظة:** الشرط الأصلي `age > 18` يستثني من عمره 18 سنة؛ اسأل التلاميذ أيهما المقصود (`>` أم `≥`): إنه درس القيمة الحدّية نفسه.

## 3. التقويم الإدماجي الرسمي: المشروع المصغر «إحصائيات القسم»

**الوضعية والمطلوب:** في القسم 9 من درس التلميذ. **المدة:** حصة تطبيقية كاملة (الحصة 8). **العمل:** فردي.

### الحل النموذجي

```text
Algorithme Statistiques_Classe
Var
    n, i, admis : Entier
    note, somme, moyenne, meilleure : Réel
Début
    Ecrire("Nombre d'élèves :")
    Lire(n)
    somme ← 0
    admis ← 0
    meilleure ← 0
    Pour i de 1 à n Faire
        Ecrire("Note de l'élève ", i, " :")
        Lire(note)
        somme ← somme + note
        Si note ≥ 10 Alors
            admis ← admis + 1
        FinSi
        Si note > meilleure Alors
            meilleure ← note
        FinSi
    FinPour
    moyenne ← somme / n
    Ecrire("Admis : ", admis, " sur ", n)
    Ecrire("Moyenne classe : ", moyenne)
    Ecrire("Meilleure note : ", meilleure)
Fin
```

### جدول التتبع (n = 5، النقاط 12، 8.5، 15، 9، 17.5)

| الدورة | i | note | somme | `note ≥ 10` | admis | `note > meilleure` | meilleure |
|---|---|---|---|---|---|---|---|
| قبل الحلقة | ؟ | ؟ | 0 | | 0 | | 0 |
| 1 | 1 | 12 | 12 | `Vrai` | 1 | `12 > 0`: `Vrai` | 12 |
| 2 | 2 | 8.5 | 20.5 | `Faux` | 1 | `8.5 > 12`: `Faux` | 12 |
| 3 | 3 | 15 | 35.5 | `Vrai` | 2 | `15 > 12`: `Vrai` | 15 |
| 4 | 4 | 9 | 44.5 | `Faux` | 2 | `9 > 15`: `Faux` | 15 |
| 5 | 5 | 17.5 | 62 | `Vrai` | 3 | `17.5 > 15`: `Vrai` | 17.5 |

بعد الحلقة: `moyenne = 62 / 5 = 12.4`. الشاشة: `Admis : 3 sur 5` ثم `Moyenne classe : 12.4` ثم `Meilleure note : 17.5`.

### نقاط تستحق النقاش عند التصحيح

- **قيمة `meilleure` الابتدائية:** 0 مقبولة لأن النقاط بين 0 و20. حل أعمّ: إسناد أول نقطة مقروءة إلى `meilleure`. يُقبل الحلّان.
- **القسمة على صفر:** إن أدخل المستخدم `n = 0` فـ `somme / n` مستحيلة. الحل المتقدم: `TantQue n < 1 Faire Lire(n) FinTantQue` بعد القراءة الأولى. لا يُعاقب غيابه، ويكافأ وجوده (نقطة إضافية).
- **اختيار الحلقة:** `Pour` هي الأنسب لأن عدد التلاميذ يُقرأ قبل الحلقة فيصبح معروفًا. يُقبل `TantQue` بعدّاد صحيح.

### شبكة التصحيح (20 نقطة)

| المعيار | ممتاز | مقبول | غير مكتمل | النقاط |
|---|---|---|---|---|
| التحليل: المدخلات والمخرجات والأنواع | كاملة وصحيحة | نقص بسيط في الأنواع | غائب | 2 |
| الهيكل والتصريح (`Algorithme`، `Var`، `Début`، `Fin`) | كامل | متغير غير مصرّح به | غائب | 2 |
| القراءة والكتابة (رسائل واضحة، نص/قيمة) | صحيحة كلها | خلط في موضع واحد | خلط متكرر | 2 |
| الحلقة (اختيار مبرّر، حدود صحيحة، `FinPour`) | صحيحة ومبرّرة | صحيحة دون تبرير | خاطئة | 4 |
| المجمّع والعدّاد (التهيئة قبل الحلقة) | الاثنان صحيحان | واحد صحيح | لا شيء | 3 |
| الشروط (`≥ 10`، أحسن نقطة، `FinSi`) | الشرطان صحيحان | شرط واحد | لا شيء | 3 |
| جدول التتبع بالمثال التجريبي | صحيح كامل | خطأ في دورة واحدة | غائب | 2 |
| التنفيذ في Algobox | يعمل ويعطي النتائج المنتظرة | يعمل بنتيجة ناقصة | لا يعمل | 2 |
| **المجموع** | | | | **20** |

> **دون حواسيب:** يُحوّل معيار «التنفيذ في Algobox» إلى تتبّع ثانٍ بمدخلات يختارها الأستاذ (مثلًا n = 3: النقاط 10، 10، 4 ← `Admis : 2 sur 3`، `Moyenne classe : 8`، `Meilleure note : 10`).

## 4. وضعية بديلة (للمعالجة أو للفوج الثاني): الصراف الآلي

**الوضعية:** رصيد حساب 5000 دج. يكتب المستخدم المبلغ الذي يريد سحبه، ويكرّر ذلك حتى يكتب 0. إن كان المبلغ أكبر من الرصيد تظهر `Solde insuffisant`، وإلا يُطرح المبلغ ويظهر الرصيد الجديد.

**مثال:** المدخلات `2000`، `4000`، `1500`، `0` يُعطي `Nouveau solde : 3000` ثم `Solde insuffisant` ثم `Nouveau solde : 1500` ثم `Au revoir`.

```text
Algorithme Distributeur
Var
    solde, montant : Réel
Début
    solde ← 5000
    Ecrire("Montant (0 = fin) :")
    Lire(montant)
    TantQue montant ≠ 0 Faire
        Si montant > solde Alors
            Ecrire("Solde insuffisant")
        Sinon
            solde ← solde - montant
            Ecrire("Nouveau solde : ", solde)
        FinSi
        Ecrire("Montant (0 = fin) :")
        Lire(montant)
    FinTantQue
    Ecrire("Au revoir")
Fin
```

| الدورة | montant | `montant ≠ 0` | `montant > solde` | solde | الشاشة |
|---|---|---|---|---|---|
| قبل الحلقة | 2000 | | | 5000 | |
| 1 | 2000 | `Vrai` | `Faux` | 3000 | `Nouveau solde : 3000` |
| 2 | 4000 | `Vrai` | `Vrai` | 3000 | `Solde insuffisant` |
| 3 | 1500 | `Vrai` | `Faux` | 1500 | `Nouveau solde : 1500` |
| — | 0 | `Faux` (خروج) | | 1500 | `Au revoir` |

> هذه الوضعية تستعمل `TantQue` لأن عدد العمليات غير معروف مسبقًا، وهي مكمّلة للمشروع المصغر الذي يستعمل `Pour`. **للمتفوقين:** رفض المبالغ السالبة بشرط مركّب.

## 5. نشاط إثرائي (للمنزل)

1. **سؤال تفكير:** حوّل خوارزمية مجموع 1 إلى 100 من `Pour` إلى `TantQue`. ما التعليمتان اللتان يجب أن تضيفهما بنفسك؟ *(الإجابة: `i ← 1` قبل الحلقة و`i ← i + 1` داخلها، مع الشرط `i ≤ 100`.)*
2. **لعبة التخمين:** الحاسوب يحفظ عددًا سريًا (ثابت `SECRET = 37`)، والمستخدم يخمّن حتى يجده، وفي كل مرة يظهر `Plus grand` أو `Plus petit`، وفي النهاية عدد المحاولات. مثال: `50`، `25`، `37` يُعطي `Plus petit`، `Plus grand`، `Trouvé en 3 essais`.
3. **Python (اختياري):** اكتب المشروع المصغر بلغة Python باستعمال `for` و`float(input())`، وقارن عدد الأسطر مع الشبه-رمز.
