أنشطة وتمارين التقويم: التعليمات الأساسية

1. التقويم التكويني (أثناء الحصص)

النشاط الأول: علب المتغيرات (دون حاسوب — الحصة 1، 10 دقائق)

  • التجهيز: ثلاث علب (أو أكواب) مكتوب عليها a وb وtmp، وبطاقات أرقام.
  • التعليمة: ينفّذ ثلاثة تلاميذ أمام القسم التعليمات التي يقرؤها زميلهم سطرًا سطرًا: a ← 4، b ← 9، ثم محاولة التبادل بـ a ← b وb ← a. يلاحظ القسم ضياع القيمة 4، ثم يُعاد النشاط بالمتغير tmp.
  • الهدف: جعل محو القيمة القديمة في الإسناد محسوسًا، وتبرير الحاجة إلى المتغير المؤقت.
  • الإجابة المنتظرة: بعد المحاولة الأولى a = 9 وb = 9؛ بعد الثانية a = 9 وb = 4.

النشاط الثاني: نص أم قيمة؟ (الحصة 2، 5 دقائق)

  • التعليمة: مع x ← 4، توقّع ما يظهر لكل من: Write("x")، Write(x)، Write(x + 1)، Write("x + 1")، Write("x = ", x). ثم تحقق في Algobox.
  • الإجابة المنتظرة: x، 4، 5، x + 1، x = 4.

النشاط الثالث: الحلقة البشرية (دون حاسوب — الحصة 5، 5 دقائق)

  • التعليمة: تلميذ «حاسوب» يحمل بطاقة S = 0. يقرأ الأستاذ For i ← 1 To 5 Do S ← S + i EndFor، ويرفع تلميذ آخر بطاقة i في كل دورة. يكتب القسم القيم المتتالية لـ S.
  • الإجابة المنتظرة: 1، 3، 6، 10، 15.

النشاط الرابع: من المخطط إلى الشبه-رمز (اختياري، Flowgorithm)

  • التعليمة: ارسم في Flowgorithm (المستعمل في الوحدة 15) مخطط «ناجح أم راسب» ثم مخطط مجموع 1 إلى 5، ونفّذهما. اكتب الشبه-رمز المقابل لكل مخطط في الكراس.
  • ملاحظة: نافذة الشفرة المصدرية (Source Code Viewer) في Flowgorithm يمكن أن تعرض المقابل بلغة Python، وهي فرصة لإثراء المتفوقين؛ لكن الصيغة المعتمدة تبقى الشبه-رمز الرسمي.

النشاط الخامس: صيّاد الأخطاء (الحصة 7، 10 دقائق)

  • التعليمة: في الخوارزمية التالية أربعة أخطاء. جدها وصحّحها.

Algorithm AverageOfThree
Var
    i, grade, S : Real
Begin
    For i ← 1 To 3 Do
        S ← 0
        Read(grade)
        S = S + grade
    EndFor
    Write("S / 3")
End
  • الإجابة المنتظرة: (1) i عدّاد فنوعه Integer؛ (2) S ← 0 تُنقل قبل الحلقة؛ (3) S = S + grade تُصحَّح إلى S ← S + grade؛ (4) Write("S / 3") تُظهر النص حرفيًا، والصحيح Write(S / 3) أو Write("المعدل: ", S / 3).

3. التقويم الإدماجي الرسمي: المشروع المصغر «إحصائيات القسم»

الوضعية والمطلوب: في القسم 9 من درس التلميذ. المدة: حصة تطبيقية كاملة (الحصة 8). العمل: فردي.

الحل النموذجي


Algorithm ClassStats
Var
    n, i, passCount : Integer
    grade, total, avg, best : Real
Begin
    Write("عدد التلاميذ:")
    Read(n)
    total ← 0
    passCount ← 0
    best ← 0
    For i ← 1 To n Do
        Write("نقطة التلميذ ", i, ":")
        Read(grade)
        total ← total + grade
        If grade ≥ 10 Then
            passCount ← passCount + 1
        EndIf
        If grade > best Then
            best ← grade
        EndIf
    EndFor
    avg ← total / n
    Write("الناجحون: ", passCount, " من ", n)
    Write("معدل القسم: ", avg)
    Write("أحسن نقطة: ", best)
End

نقاط تستحق النقاش عند التصحيح

  • قيمة best الابتدائية: 0 مقبولة لأن النقاط بين 0 و20. حل أعمّ: إسناد أول نقطة مقروءة إلى best. يُقبل الحلّان.
  • القسمة على صفر: إن أدخل المستخدم n = 0 فـ total / n مستحيلة. الحل المتقدم: While n < 1 Do Read(n) EndWhile بعد القراءة الأولى. لا يُعاقب غيابه، ويكافأ وجوده (نقطة إضافية).
  • اختيار الحلقة: For هي الأنسب لأن عدد التلاميذ يُقرأ قبل الحلقة فيصبح معروفًا. يُقبل While بعدّاد صحيح.

4. وضعية بديلة (للمعالجة أو للفوج الثاني): الصراف الآلي

الوضعية: رصيد حساب 5000 دج. يكتب المستخدم المبلغ الذي يريد سحبه، ويكرّر ذلك حتى يكتب 0. إن كان المبلغ أكبر من الرصيد تظهر الرصيد غير كافٍ، وإلا يُطرح المبلغ ويظهر الرصيد الجديد.

مثال: المدخلات 2000، 4000، 1500، 0 يُعطي الرصيد الجديد: 3000 ثم الرصيد غير كافٍ ثم الرصيد الجديد: 1500 ثم إلى اللقاء.


Algorithm CashMachine
Var
    balance, amount : Real
Begin
    balance ← 5000
    Write("المبلغ (0 للإنهاء):")
    Read(amount)
    While amount ≠ 0 Do
        If amount > balance Then
            Write("الرصيد غير كافٍ")
        Else
            balance ← balance - amount
            Write("الرصيد الجديد: ", balance)
        EndIf
        Write("المبلغ (0 للإنهاء):")
        Read(amount)
    EndWhile
    Write("إلى اللقاء")
End

هذه الوضعية تستعمل While لأن عدد العمليات غير معروف مسبقًا، وهي مكمّلة للمشروع المصغر الذي يستعمل For. للمتفوقين: رفض المبالغ السالبة بشرط مركّب.

5. نشاط إثرائي (للمنزل)

  1. سؤال تفكير: حوّل خوارزمية مجموع 1 إلى 100 من For إلى While. ما التعليمتان اللتان يجب أن تضيفهما بنفسك؟ (الإجابة: i ← 1 قبل الحلقة وi ← i + 1 داخلها، مع الشرط i ≤ 100.)
  2. لعبة التخمين: الحاسوب يحفظ عددًا سريًا (ثابت SECRET = 37)، والمستخدم يخمّن حتى يجده، وفي كل مرة يظهر أكبر أو أصغر (العدد السري أكبر أو أصغر من التخمين)، وفي النهاية عدد المحاولات. مثال: 50، 25، 37 يُعطي أصغر، أكبر، وجدته في 3 محاولات.
  3. Python (اختياري): اكتب المشروع المصغر بلغة Python باستعمال for وfloat(input())، وقارن عدد الأسطر مع الشبه-رمز.
