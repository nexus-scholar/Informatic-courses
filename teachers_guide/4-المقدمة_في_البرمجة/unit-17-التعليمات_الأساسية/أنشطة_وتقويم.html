أنشطة وتمارين التقويم: التعليمات الأساسية

1. التقويم التكويني (أثناء الحصص)

النشاط الأول: علب المتغيرات (دون حاسوب — الحصة 1، 10 دقائق)

  • التجهيز: ثلاث علب (أو أكواب) مكتوب عليها a وb وtmp، وبطاقات أرقام.
  • التعليمة: ينفّذ ثلاثة تلاميذ أمام القسم التعليمات التي يقرؤها زميلهم سطرًا سطرًا: a ← 4، b ← 9، ثم محاولة التبادل بـ a ← b وb ← a. يلاحظ القسم ضياع القيمة 4، ثم يُعاد النشاط بالمتغير tmp.
  • الهدف: جعل محو القيمة القديمة في الإسناد محسوسًا، وتبرير الحاجة إلى المتغير المؤقت.
  • الإجابة المنتظرة: بعد المحاولة الأولى a = 9 وb = 9؛ بعد الثانية a = 9 وb = 4.

النشاط الثاني: نص أم قيمة؟ (الحصة 2، 5 دقائق)

  • التعليمة: مع x ← 4، توقّع ما يظهر لكل من: Ecrire("x")، Ecrire(x)، Ecrire(x + 1)، Ecrire("x + 1")، Ecrire("x = ", x). ثم تحقق في Algobox.
  • الإجابة المنتظرة: x، 4، 5، x + 1، x = 4.

النشاط الثالث: الحلقة البشرية (دون حاسوب — الحصة 5، 5 دقائق)

  • التعليمة: تلميذ «حاسوب» يحمل بطاقة S = 0. يقرأ الأستاذ Pour i de 1 à 5 Faire S ← S + i FinPour، ويرفع تلميذ آخر بطاقة i في كل دورة. يكتب القسم القيم المتتالية لـ S.
  • الإجابة المنتظرة: 1، 3، 6، 10، 15.

النشاط الرابع: من المخطط إلى الشبه-رمز (اختياري، Flowgorithm)

  • التعليمة: ارسم في Flowgorithm (المستعمل في الوحدة 15) مخطط «ناجح أم راسب» ثم مخطط مجموع 1 إلى 5، ونفّذهما. اكتب الشبه-رمز المقابل لكل مخطط في الكراس.
  • ملاحظة: نافذة الشفرة المصدرية (Source Code Viewer) في Flowgorithm يمكن أن تعرض المقابل بلغة Python، وهي فرصة لإثراء المتفوقين؛ لكن الصيغة المعتمدة تبقى الشبه-رمز الرسمي.

النشاط الخامس: صيّاد الأخطاء (الحصة 7، 10 دقائق)

  • التعليمة: في الخوارزمية التالية أربعة أخطاء. جدها وصحّحها.

Algorithme Moyenne_Trois
Var
    i, note, S : Réel
Début
    Pour i de 1 à 3 Faire
        S ← 0
        Lire(note)
        S = S + note
    FinPour
    Ecrire("S / 3")
Fin
  • الإجابة المنتظرة: (1) i عدّاد فنوعه Entier؛ (2) S ← 0 تُنقل قبل الحلقة؛ (3) S = S + note تُصحَّح إلى S ← S + note؛ (4) Ecrire("S / 3") تُظهر النص حرفيًا، والصحيح Ecrire(S / 3) أو Ecrire("Moyenne : ", S / 3).

النشاط السادس (إثراء Python): صيّاد الأخطاء في Python

2. محطة منتصف الوحدة: سلّم التنقيط

الأسئلة في درس التلميذ (بعد القسم 4)، والإجابات في «بطاقة إجابة مختصرة للأستاذ».

3. التقويم الإدماجي الرسمي: المشروع المصغر «إحصائيات القسم»

الوضعية والمطلوب: في القسم 9 من درس التلميذ. المدة: حصة تطبيقية كاملة (الحصة 8). العمل: فردي.

الحل النموذجي


Algorithme Statistiques_Classe
Var
    n, i, admis : Entier
    note, somme, moyenne, meilleure : Réel
Début
    Ecrire("Nombre d'élèves :")
    Lire(n)
    somme ← 0
    admis ← 0
    meilleure ← 0
    Pour i de 1 à n Faire
        Ecrire("Note de l'élève ", i, " :")
        Lire(note)
        somme ← somme + note
        Si note ≥ 10 Alors
            admis ← admis + 1
        FinSi
        Si note > meilleure Alors
            meilleure ← note
        FinSi
    FinPour
    moyenne ← somme / n
    Ecrire("Admis : ", admis, " sur ", n)
    Ecrire("Moyenne classe : ", moyenne)
    Ecrire("Meilleure note : ", meilleure)
Fin

نقاط تستحق النقاش عند التصحيح

  • قيمة meilleure الابتدائية: 0 مقبولة لأن النقاط بين 0 و20. حل أعمّ: إسناد أول نقطة مقروءة إلى meilleure. يُقبل الحلّان.
  • القسمة على صفر: إن أدخل المستخدم n = 0 فـ somme / n مستحيلة. الحل المتقدم: TantQue n < 1 Faire Lire(n) FinTantQue بعد القراءة الأولى. لا يُعاقب غيابه، ويكافأ وجوده (نقطة إضافية).
  • اختيار الحلقة: Pour هي الأنسب لأن عدد التلاميذ يُقرأ قبل الحلقة فيصبح معروفًا. يُقبل TantQue بعدّاد صحيح.

4. وضعية بديلة (للمعالجة أو للفوج الثاني): الصراف الآلي

الوضعية: رصيد حساب 5000 دج. يكتب المستخدم المبلغ الذي يريد سحبه، ويكرّر ذلك حتى يكتب 0. إن كان المبلغ أكبر من الرصيد تظهر Solde insuffisant، وإلا يُطرح المبلغ ويظهر الرصيد الجديد.

مثال: المدخلات 2000، 4000، 1500، 0 يُعطي Nouveau solde : 3000 ثم Solde insuffisant ثم Nouveau solde : 1500 ثم Au revoir.


Algorithme Distributeur
Var
    solde, montant : Réel
Début
    solde ← 5000
    Ecrire("Montant (0 = fin) :")
    Lire(montant)
    TantQue montant ≠ 0 Faire
        Si montant > solde Alors
            Ecrire("Solde insuffisant")
        Sinon
            solde ← solde - montant
            Ecrire("Nouveau solde : ", solde)
        FinSi
        Ecrire("Montant (0 = fin) :")
        Lire(montant)
    FinTantQue
    Ecrire("Au revoir")
Fin

5. نشاط إثرائي (للمنزل)

  1. سؤال تفكير: حوّل خوارزمية مجموع 1 إلى 100 من Pour إلى TantQue. ما التعليمتان اللتان يجب أن تضيفهما بنفسك؟ (الإجابة: i ← 1 قبل الحلقة وi ← i + 1 داخلها، مع الشرط i ≤ 100.)
  2. لعبة التخمين: الحاسوب يحفظ عددًا سريًا (ثابت SECRET = 37)، والمستخدم يخمّن حتى يجده، وفي كل مرة يظهر Plus grand أو Plus petit، وفي النهاية عدد المحاولات. مثال: 50، 25، 37 يُعطي Plus petit، Plus grand، Trouvé en 3 essais.
  3. Python (اختياري): اكتب المشروع المصغر بلغة Python باستعمال for وfloat(input())، وقارن عدد الأسطر مع الشبه-رمز.
