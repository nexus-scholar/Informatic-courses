مختبر تفاعلي للوحدتين 16 و17: اقرأ الخوارزمية سطرًا بسطر، نفّذها بنفسك، عدّلها، ثم تدرّب. {% .lead %}

- **شرح:** تظهر الخوارزمية جزءًا بعد جزء، مع شرح كل سطر جديد.
- **تنفيذ:** اكتب القيم التي يُدخلها المستخدم، وتابع السطر النشط والذاكرة والشاشة وجدول التتبع. زر «عدّل الخوارزمية» يتيح لك تغييرها وتجربة أفكارك؛ وإذا أخطأت تظهر رسالة تحدّد السطر والسبب.
- **تدريب:** توقّع المخرج أو القيمة النهائية لمتغير أو عدد الدورات أو جواب الشرط، ثم تحقّق بالتنفيذ.

## طريقة الاستعمال

| الفعل | على الحاسوب وجهاز العرض | على الهاتف |
|---|---|---|
| الشريحة أو الخطوة التالية | السهم ← أو مفتاح المسافة | زر «التالي» أو السحب نحو اليمين |
| الشريحة أو الخطوة السابقة | السهم → | زر «السابق» أو السحب نحو اليسار |
| إدخال الرموز ← ≠ ≤ ≥ | لوحة الرموز فوق المحرّر | لوحة الرموز فوق المحرّر |
| ملء الشاشة | زر ملء الشاشة أو المفتاح F | زر ملء الشاشة |
