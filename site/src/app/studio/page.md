مختبر تفاعلي يرافق الوحدات 15 و16 و17: اختر مثالًا، ثم تنقّل بين ثلاثة أوضاع. {% .lead %}

- **شرح:** يُبنى المخطط شكلًا بعد شكل، مع شرح قصير لكل شريحة.
- **تنفيذ:** أدخل قيمًا وتابع الشكل النشط والذاكرة والشاشة وجدول التتبع خطوة بخطوة.
- **تدريب:** توقّع المخرج أو الفرع أو عدد الدورات، ثم تحقّق بالتنفيذ.

{% flowchart-studio example="average" /%}

## طريقة الاستعمال

| الفعل | على الحاسوب وجهاز العرض | على الهاتف |
|---|---|---|
| الشريحة أو الخطوة التالية | السهم ← أو مفتاح المسافة | زر «التالي» أو السحب نحو اليمين |
| الشريحة أو الخطوة السابقة | السهم → | زر «السابق» أو السحب نحو اليسار |
| ملء الشاشة | زر ملء الشاشة أو المفتاح F | زر ملء الشاشة |
| الخروج من ملء الشاشة | Esc | الزر نفسه |

{% callout title="للأستاذ" %}
في القسم، افتح المختبر بملء الشاشة على جهاز العرض واستعمل وضع «شرح» كعرض تقديمي، ثم «تنفيذ» بقيم يقترحها التلاميذ. تُحفظ نتائج التدريب على جهاز التلميذ فقط، دون حسابات ودون أي بيانات شخصية.
{% /callout %}
