## 1. قاعدة التنظيم والتوزيع الزمني المعتمد

| العنصر البيداغوجي | البيان والتفصيل |
| :--- | :--- |
| **المادة والمستوى** | الإعلام الآلي — السنة الأولى ثانوي (1AS) |
| **المرجعية البيداغوجية** | التدرجات السنوية الرسمية لوزارة التربية الوطنية (الجزائر) |
| **الكفاءة الشاملة** | اكتساب المفاهيم القاعدية حول بيئة الحاسوب، واستخدام البرمجيات المكتبية، وتطوير التفكير المنطقي والخوارزمي وحل المشكلات |
| **الحجم الزمني الأسبوعي** | 03 ساعات: ساعة نظرية للقسم كاملاً وساعتان تطبيقيتان لكل فوج مخبري |
| **أسلوب التقويم** | تقويم تكويني مرحلي بعد كل وحدة، وتقويم فصلي (فروض واختبارات) ومشاريع تطبيقية |

{% callout title="تطوير المنهاج إلى بيئة 2026 الرقمية" %}
تم استبدال المفاهيم والأنظمة القديمة في الكتاب المرجعي بالتقنيات الحديثة:
- الانتقال من Windows XP/7/8 إلى **Windows 11** مع بيئة **Ubuntu Linux**.
- استخدام حزم مكتبية عصرية (**Office 365 / Office 2021 / LibreOffice**).
- التركيز على الأمان الرقمي الحديث، المصادقة الثنائية (2FA)، والحوسبة السحابية.
- ربط الخوارزميات والمخططات الانسيابية بتطبيقات برمجية معاصرة (مثل لغة Python).
{% /callout %}

## 3. كيفية استخدام هذه المنصة

1. **للتلميذ:**
   - قراءة الدرس قبل الحصة لمواكبة التعلمات.
   - متابعة الخطوات العملية في الحصص المخبرية التطبيقية.
   - التدرب على الأسئلة والأنشطة التقويمية الموجودة في نهاية كل وحدة.
2. **للأستاذ:**
   - اعتماد التسلسل المنهجي في إعداد المذكرات الصفية.
   - استخدام الأمثلة المحدثة لربط المفاهيم بواقع التلاميذ واحتياجاتهم اليومية.
   - الاستفادة من ميزة البحث الفوري لاسترجاع أي مصطلح باللغة العربية أو الفرنسية أو الإنجليزية.

{% callout type="warning" title="توجيه للتلاميذ في المخبر المدرسي" %}
احرص دائماً على تطبيق قواعد السلامة الصحية (Ergonomie) داخل مخبر الثانوية، والحفاظ على سلامة التجهيزات والأسلاك والشبكة المحلية، وتجنب استعمال وسائط التخزين الخارجية (فلاش ديسك) دون فحصها بمضاد الفيروسات.
{% /callout %}
