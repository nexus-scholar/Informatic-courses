# أرشيف المشروع

يحفظ هذا المجلد مواد مرجعية لا تدخل في سير العمل اليومي. لم يُحذف أي محتوى عند التنظيم.

| المسار | المحتوى | الاستعمال |
|---|---|---|
| `legacy-reference/book/` | OCR كامل للكتاب وصوره | الرجوع إلى النص الأصلي فقط |
| `legacy-reference/sources/` | PDF الكتاب، التدرج، وملفات الدروس المصدرية | التحقق من المصدر فقط |
| `planning-legacy/` | كل وثائق التخطيط السابقة | سجل تاريخي وتتبّع القرارات |

المواد النشطة هي `courses/lessons/` للمتعلمين، و`teachers_guide/` للأستاذ، و`planning/التخطيط_السنوي.md` للتخطيط.
