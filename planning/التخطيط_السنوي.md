## 4. ملاحظات تشغيلية

- تُجزّأ الحصص التطبيقية إلى فوجين؛ أما النظري فيُنجز مع القسم كاملاً.
- تُستعمل مذكرات التنفيذ والأنشطة والتقويم من `teachers_guide/`، لا من ملفات التخطيط.
- المادة الطالبية المعتمدة في `courses/lessons/` فقط. تُنشأ صفحات الموقع تلقائياً منها؛ لا تعدّل النسخ الموجودة في `site/src/app/docs/` يدوياً.
- التواريخ والأسابيع في خطة التوزيع السابقة **نموذج تنظيمي** وليست رزنامة سنة ثابتة؛ تُكيَّف مع رزنامة المؤسسة والعطل الفعلية.

### دورة تعديل مختصرة

1. عدّل درس التلميذ في `courses/lessons/` أو مورد الأستاذ في `teachers_guide/`.
2. شغّل `python courses/convert_lessons.py` إذا تغيّر درس Markdown، للحفاظ على نسخة HTML المحلية.
3. شغّل `python courses/generate_site_docs.py` ثم `python courses/verify_site_content.py`.
4. شغّل `npm --prefix site run build` قبل الدفع إلى GitHub؛ يتكرر التحقق نفسه تلقائياً في GitHub Actions.
